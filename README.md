# 😴 Sleep, Mobile Usage & Stress Dataset

A comprehensive dataset of **15,000 records** exploring the relationships between mobile phone usage, sleep patterns, stress levels, and lifestyle factors across diverse occupational groups.

---

## 📋 Dataset Overview

| Property | Details |
|---|---|
| **File** | `sleep_mobile_stress_dataset_15000_csv.xlsx` |
| **Records** | 15,000 |
| **Features** | 13 columns |
| **Format** | Excel (.xlsx) |

---

## 📊 Columns Description

| Column | Type | Description |
|---|---|---|
| `user_id` | Integer | Unique identifier for each participant |
| `age` | Integer | Age of the participant |
| `gender` | String | Gender (Male / Female / Other) |
| `occupation` | String | Job role (e.g., Teacher, Engineer, Doctor, Student...) |
| `daily_screen_time_hours` | Float | Total daily screen time on mobile (in hours) |
| `phone_usage_before_sleep_minutes` | Integer | Minutes of phone usage before sleeping |
| `sleep_duration_hours` | Float | Total sleep duration per night (in hours) |
| `sleep_quality_score` | Float | Subjective sleep quality score (1–10) |
| `stress_level` | Float | Self-reported stress level (1–10) |
| `caffeine_intake_cups` | Integer | Number of caffeinated drinks per day |
| `physical_activity_minutes` | Integer | Daily physical activity duration (in minutes) |
| `notifications_received_per_day` | Integer | Number of mobile notifications received daily |
| `mental_fatigue_score` | Float | Mental fatigue rating (1–10) |

## 💡 Potential Use Cases

- **Sleep quality analysis** — How does screen time and phone usage before bed affect sleep?
- **Stress prediction** — Build ML models to predict stress levels from lifestyle data
- **Occupation-based insights** — Compare sleep and stress patterns across professions
- **Correlation studies** — Explore links between caffeine, activity, notifications, and mental fatigue
- **Data visualization** — Dashboard development for health and wellness analytics
